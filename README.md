# DefenseGame_spgp2026
스마트폰 게임 프로그래밍에서 한 학기동안 개발할 게임에 대한 설명을 나타낸 글입니다.
강의 때 배우는 'TuDefence'에서 한차원 업그레이드하여 전략적 요소를 극대화시켜봤습니다.

## 게임 컨셉
* 에테르 가디언즈
    * High Concept
    * 핵심 메카닉
        * 배치 시스템
            * 화면 하단의 유닛 아이콘을 터치하여 필드의 원하는 위치로 드래그 혹은 선택하면 유닛이 배치된다.
            * 유닛을 배치할 때는 현재 가지고 있는 자원을 소모하여 배치할 수 있다.
        * 자원 관리
            * 시간이 지남에 따라 자동으로 에너지가 차오른다.
            * 에너지 수치에 따라 배치할 수 있는 유닛의 종류가 다르다.
        * 자동 공격 및 타겟팅
            * 배치된 유닛은 사거리 안에 적이 들어오면 자동으로 가장 가까운 적을 공격한다.
        * 스킬
            * 유닛마다 특별한 스킬을 가지고 있다.
            * 유닛마다 패시브 스킬과 액티브 스킬을 가지고 있다.

## 개발 범위
* 유닛
    * 각 유닛들의 전체적인 특징을 설명
    * 플레이어 유닛
        * 전사
            * 높은 체력
            * 높은 방어력
            * 높은 마법 저항력
            * 물리 공격
            * 짧은 사거리
        * 도적
            * 빠른 공격 속도
            * 낮은 체력
            * 낮은 에너지 소모량
            * 물리 공격
            * 짧은 사거리
        * 궁수
            * 물리 공격
            * 긴 사거리
            * 같은 사거리 내 원거리 유닛 우선 타겟팅
        * 마법사
            * 마법 공격
            * 긴 사거리
        * 성직자
            * 마법 공격
            * 서포팅 스킬
                * 힐링
                * 에너지 수급률 증가
                * 상태 이상기
    * 적 유닛
        * 일반형태
            * 가장 기본이 되는 적의 형태
            * 평균의 능력치
            * 짧은 사거리
        * 탱커형태
            * 높은 체력
            * 높은 방어력
            * 높은 마법 저항력
            * 짧은 사거리
        * 물량형태
            * 낮은 체력
            * 짧은 시간 내에 많은 적이 생성
        * 특수형태
            * 특수 능력 보유
                * 은신
                * 자체 힐링
                * 상태 이상기
        * 원거리형태
            * 물리 형태
            * 마법 형태
            * 긴 사거리
            * 같은 사거리 내 원거리 유닛 우선 타겟팅

* 맵
    * 타일 기반 배치 시스템
        * 맵 전체를 일정한 크기의 그리드로 나누어 관리
    * 경로 시스템
        * 적 유닛이 생성 지점에서 목표 지점까지 이동하는 정해진 경로를 구현
        * 최소 거리뿐만 아니라 다양한 경로를 추가하여 전략적 요소 부여
    * 환경/지형 기믹
        * 시야 방해
            * 안개나 숲과 같은 지형에 의해 적이 잠시 가려지는 효과
        * 지형 버프/디버프
            * 특정 타일에 배치시 버프/디버프가 부여됨
    * 스테이지 구성
        * 평원
            * 장애물이 적고, 경로가 단순한 튜토리얼 성격의 맵
        * 계곡
            * 환경/지형 기믹이 추가된 맵
        * 성
            * 환경/지형 기믹이 추가된 맵
            * 여러 갈래에서 적이 등장

## 예상 게임 실행 흐름
* Title Scene
    * 화면 구성
        * 게임 로고, 배경 이미지, 'Game Start'버튼
    * 기능
        * Start 버튼 클릭 시 Game Scene으로 전환
* Game Scene
    * 화면 구성
        * 상단
            * 목표 처치 수
            * 경과 시간
            * 웨이브 정보
        * 중단
            * 적들이 이동하는 경로를 실시간으로 나타냄
            * 유닛을 배치할 수 있는 타일
        * 하단
            * 배치 가능한 유닛 리스트
            * 현재 보유 에너지
    * 주요 로직
        * 자원 수급
            * 시간이 지남에 따라 에너지 자동 증가
        * 유닛 배치
            * 하단 아이톤을 드래그 혹은 선택하여 필드에 놓으면 해당 위치에 GameObject 생성 및 자원 차감
        * 전투
            * 생성된 유닛이 사거리 내의 적을 자동 타겟팅하여 공격
        * 적 생성
            * 일정 간격으로 다양한 형태의 적 출현
* Result Scene
    * 진입 조건
        * 승리
            * 모든 웨이브의 적을 처치했을 때
        * 패배
            * 적이 방어 위치에 도달하여 HP가 0이 되었을 때
    * 화면 구성
        * 승리/패배 문구 출력
        * 이번 판에서 소요된 시간 출력
        * Title Scene으로 돌아가기 버튼
